# iRipper

VBA-макрос экспорта уникальных packed batch с листа **Ripper I**.

## Что делает макрос

1. Берёт данные **только с листа `Ripper I`** (имя файла книги не важно — можно переименовывать ежедневно).
2. Копирует диапазон **F:M** **как значения** (без формул).
3. Строка копируется, если в **Packed batch (F)** есть значение.
4. Уникальность проверяется по **Batch Id (J)** — уже существующие в архиве Batch Id пропускаются.
5. Шапка (F1:M1) копируется **только при первом создании** архива.
6. Архив **всегда один файл** `C:\AUTO\iRipper\Ripper_I_PackedBatches.xlsx`: макрос **только дописывает**, не очищает и не перезаписывает старые строки (даже если исходную книгу переименовали).

## Установка

**Вариант A — импорт файла (предпочтительно):**
1. Откройте книгу с листом `Ripper I`.
2. `Alt + F11` → **File → Import File…** → выберите `vba/ExportRipperI.bas`.
3. Сохраните книгу (`.xlsm` / `.xlsb`).

**Вариант B — вставка кода в Module:**
1. `Alt + F11` → Insert → Module.
2. Вставьте содержимое `ExportRipperI.bas`.
3. Если в начале есть строка `Attribute VB_Name = "..."`, **удалите её** — иначе будет Compile error.

Путь архива меняется в константе `DEST_PATH`.

## Запуск

- `Alt + F8` → `ExportUniquePackedBatches` → Run  
или назначьте макрос кнопке на листе / панели быстрого доступа.

## Результат

В архиве на листе `Ripper I` накапливаются колонки:

| A | B | C | D | E | F | G | H |
|---|---|---|---|---|---|---|---|
| Packed batch | Year | Month | Date | Batch Id | Ripper Code | Reject weight | Ripper weight |

При повторных запусках добавляются только новые Batch Id.
